# U11 Starfighter

Private source for U11 Starfighter, a 3D rail shooter built with C++ and raylib.

This repository is the t275 project state, **code only**. Game asset binaries (models, textures, audio, fonts, and Blender files) are not in git. See [ASSETS.md](ASSETS.md) for how to get them and how to add or change one.

## Build

- Windows: `tools/build-windows.ps1` and `CMakeLists.txt`
- Tablet / arm64: `tools/build-arm64-wsl.sh` and `Makefile`
